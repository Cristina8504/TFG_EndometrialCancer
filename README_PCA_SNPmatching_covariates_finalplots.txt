**Evaluation of DNA Quality and Case-Cohort Analysis of Endometrial Cancer-Associated SNPs**

### 2. `README_PCA_SNPmatching_covariates_finalplots.txt`

This file explains the purpose, inputs, outputs and interpretation of the script.

## Purpose of the script

This script documents and organises several analysis steps:

1. Loading PCA/MDS results, FAM, BIM, metadata and raw genotype files.
2. Matching candidate SNPs against SNPs present in the BIM file.
3. Creating a PLINK SNP extraction list.
4. Visualising population structure using PC1 and PC2.
5. Extracting phenotype information and creating a fixed FAM file.
6. Creating a covariate file containing age and principal components.
7. Adding confidence intervals to GLM/meta-analysis results.
8. Preparing final TFG figures.
9. Creating a SNP list for LD analysis.

## Main input files

The script uses several files generated by PLINK/Ricopili and by previous R analyses:

### PCA/MDS files

- `emc_pca.menv.trans.mds`
- `emc_pca_eur.menv.trans.mds`

These contain principal components used to assess population structure.

### PLINK files

- `.fam`
- `.bim`
- `.meta`
- `.raw`

The `.fam` file contains sample IDs and phenotype information.

The `.bim` file contains SNP information, including chromosome, SNP ID, position and alleles.

The `.raw` files contain extracted genotype data and phenotype columns.

### SNP reference file

- `clean_SNPs_with_pvalues.xlsx`

This file contains the candidate SNPs selected from literature/GWAS Catalog.

### Meta-analysis result file

- `meta_analysis_results2.xlsx`

This file is used to create final TFG plots, including candidate SNP classification, meta-analysis forest plot and literature concordance plot.

## Main steps

### 1. Load PCA/MDS, FAM, BIM and RAW data

The script loads:

- PCA results for all samples
- PCA results for European samples
- PLINK FAM file
- PLINK BIM file
- metadata file
- raw genotype files for Round 1 and Round 2

### 2. Clean BIM file and match candidate SNPs

The BIM file contains SNP identifiers as stored in the genotype dataset.

Some IDs contain technical prefixes such as:

- `GSA-`
- `exm-`

These prefixes are removed to create a clean rsID column.

Candidate SNPs from the reference Excel file are compared with the cleaned BIM SNP IDs.

The script creates:

- `snps_present`: candidate SNPs present in the genotype dataset
- `snps_missing`: candidate SNPs absent from the genotype dataset

The present SNPs are exported to Excel.

A PLINK extraction list is also created using the real SNP names from the BIM file.

### 3. Population structure plot

The script plots PC1 vs PC2 from the MDS/PCA file.

Samples are labelled as cases or controls based on the FID pattern.

This plot helps visualise population structure and whether cases and controls separate by ancestry.

### 4. Phenotype extraction

The phenotype column is extracted from the raw genotype files.

The script matches phenotype information to the FAM file using FID and IID.

This creates a phenotype file suitable for PLINK.

### 5. Fixed FAM file

The original FAM file did not contain the required phenotype labels.

The script creates a lookup table from IID to phenotype and replaces column V6 in the FAM file.

Missing phenotypes are coded as `-9`, which is the standard missing phenotype code in PLINK.

A corrected FAM file is exported.

### 6. Covariate file creation

Age information is merged with PCA/MDS results using sample ID.

The script creates a covariate file containing:

- FID
- IID
- age
- PC1
- PC2
- PC3
- PC4
- PC5

This file can be used in PLINK logistic regression to adjust for age and population structure.

### 7. Confidence intervals for GLM results

The script adds beta-scale 95% confidence intervals for Round 1 and Round 2 using:

`BETA ± 1.96 × SE`

These are useful for plotting and interpretation.

### 8. Manual addition of rs4430796

The original script manually added rs4430796 to the Round 1 and Round 2 GLM result tables using previously verified statistics.

This step should only be used if the SNP was missing from the table due to filtering or file-generation issues and the values have been checked.

The cleaned script includes safeguards to add the row only if it is not already present.

### 9. Forest plot by genotyping round

The script creates a forest plot comparing SNP odds ratios in Round 1 and Round 2.

SNPs are grouped into categories:

- General cancer
- Primary endometrial cancer
- Pleiotropic

The plot shows:

- odds ratio
- 95% confidence interval
- SNP category
- separate panels for each round

### 10. LD SNP list

The script creates a text file containing three HNF1B/17q12 variants:

- rs7501939
- rs4430796
- rs11651755

This file can be used in PLINK to perform linkage disequilibrium analysis.

### 11. Candidate SNP category plot

The script creates a bar plot showing how many candidate SNPs belong to each category:

- Endometrial cancer GWAS
- Multi-cancer GWAS
- Pleiotropic variants

This corresponds to the candidate SNP classification figure in the TFG.

### 12. Meta-analysis forest plot

The script reads meta-analysis results and creates a forest plot showing:

- meta-analysis OR
- 95% confidence interval
- direction of effect

The x-axis is shown on a log scale.

### 13. Literature concordance plot

The script compares odds ratios from the current meta-analysis with odds ratios reported in the literature.

A connected dot plot is created, where each SNP has:

- one point for the current meta-analysis OR
- one point for the published literature OR
- a dashed line connecting both estimates

This plot helps visualise concordance or disagreement between the current findings and published GWAS results.

## Important corrections made to the original code

The original code contained several inconsistencies that were corrected:

1. `write.table("bim2")` did not write the BIM table correctly and was removed.
2. `bim$SNP_rs` was used but not created. The cleaned script uses `bim$SNP_clean`.
3. `mds2` was used but not loaded. The cleaned script uses `mds`.
4. The `covar` file originally used `mds$AGE`, but AGE was not in `mds`. The cleaned script merges AGE into MDS first.
5. `getwd()log_add` was invalid and removed.
6. There was an incorrect line `glm2 <- rbind(glm1, new_row)`. The cleaned version correctly adds `new_row_round2` to `glm2`.
7. In the forest plot, `scale_x_log10()` was not connected to the rest of the ggplot chain. The cleaned version fixes this.
8. There was an extra closing parenthesis after `writeLines(snpsLD, "hnf1b_snps.txt")`. This was removed.
9. Several repeated `library()` calls were removed.
10. The code now checks that objects exist before using them in optional blocks.
